🧠 Projeto PSICO – Chatbot de Apoio Psicológico
📌 Sobre o Projeto

O Projeto PSICO é um chatbot desenvolvido com o objetivo de simular um atendimento inicial de apoio psicológico, permitindo que o usuário interaja com o sistema por meio de perguntas e respostas.

O chatbot realiza uma triagem básica, identificando sentimentos ou situações relatadas pelo usuário e oferecendo respostas de orientação, podendo também direcionar para ajuda profissional.

Este projeto foi desenvolvido com fins educacionais, com foco em aprendizado de programação, lógica e desenvolvimento de sistemas interativos.

🎯 Objetivos
Criar um chatbot interativo
Simular uma triagem psicológica inicial
Praticar lógica de programação
Desenvolver um sistema de interação com usuário
Explorar conceitos de chatbots e inteligência artificial básica
⚙️ Tecnologias Utilizadas
Python
Estruturas condicionais
Manipulação de texto
Lógica de chatbot baseada em palavras-chave
💬 Exemplo de Interação
Chatbot: Olá! Como você está se sentindo hoje?

Usuário: Estou me sentindo muito ansioso.

Chatbot: Entendo. A ansiedade pode ser difícil de lidar. 
Você gostaria de conversar mais sobre isso ou receber algumas sugestões para ajudar?
🧩 Funcionalidades
Início de conversa automática
Reconhecimento de palavras-chave
Respostas automáticas baseadas em emoções
Interação em tempo real com o usuário
Simulação de apoio psicológico inicial
